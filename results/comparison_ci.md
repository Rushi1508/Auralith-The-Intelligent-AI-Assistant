## What this changes

- **The retrieval gains are real.** Every retrieval metric's interval excludes
  zero, including MRR, which is k-independent.
- **The answer-correctness gain is not established.** +0.107 (10/28 -> 13/28)
  has an interval of roughly [-0.11, +0.32]. Three questions flipping is
  within what resampling 28 questions produces by chance.
- **The false-abstention "regression" is not established either.** 3/26 -> 5/26
  has an interval that includes zero. It is still worth fixing, since it is a
  mechanism we can see in the answers, but it is not a measured regression.
- **abstention_accuracy on n=2 carries no information**, as already stated.

Retrieval changes are detectable on this question set. End-to-end changes of
about 0.1 are not. Showing a generation-side improvement needs either a large
effect or more questions.
